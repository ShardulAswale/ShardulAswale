### Applied ML results

For my MSc flight disruption project, I processed data derived from **1.3 billion ADS-B records**, engineered flight-level features and compared Logistic Regression, Random Forest and XGBoost using chronological train/test splits. The selected model achieved **71.2% disrupted-flight recall**, **55.0% precision** and **80.5% weighted F1** across the reported evaluation. The project included a Streamlit dashboard and SHAP explanations.

These are results from my study dataset and experimental setup; see the project documentation and notebooks for the pipeline.
